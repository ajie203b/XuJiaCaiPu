# 徐家菜谱 Android 应用

一个基于 Kotlin + Jetpack Compose 开发的精美菜谱应用，帮助你查找、学习各种美食的制作方法，解决"今天吃什么"的世纪难题。

## ✨ 核心功能

### 🏠 首页浏览

- **357 道菜品**：涵盖素菜、荤菜、早餐、汤、其他五大分类
- **精美卡片**：每道菜品以卡片形式展示，包含菜品图片、名称和难度星级
- **分类筛选**：顶部标签栏快速切换分类，一键筛选想看的菜品
- **智能搜索**：支持按菜名或食材名称搜索，快速找到目标菜品
- **回到顶部**：滚动超过 3 个菜品后，右下角出现快捷返回顶部按钮

### 📖 菜品详情

- **完整信息**：展示菜品介绍、必备原料和工具、计算、操作步骤、附加内容
- **难度评级**：1-5 星难度标识，一目了然
- **高清大图**：每道菜品配有精美实拍图片
- **收藏功能**：点击右上角心形图标收藏/取消收藏

### ❤️ 我的收藏

- **统一管理**：所有收藏菜品集中展示
- **分类筛选**：支持按分类快速筛选收藏内容
- **图片展示**：收藏卡片展示菜品图片、名称、难度星级
- **快速访问**：点击卡片直接跳转详情页
- **空状态提示**：未收藏时显示友好引导

### 🎲 为你推荐

- **随机推荐**：不知道吃什么？让运气来决定！
- **分类筛选**：可勾选参与随机的分类，缩小推荐范围
- **动画效果**：开始后快速轮播菜品名，停止后定格结果
- **结果锁定**：停止后菜品固定不变，跳转详情页返回后依然保持
- **换一个**：不满意可直接点击"换一个"快速重新推荐
- **卡片展示**：推荐结果以精美卡片呈现（图片+名称+星级）

### 💡 烹饪技巧

- **18 篇技巧文章**：涵盖去腥、焯水、炒与煎、煮、腌、蒸、微波炉、空气炸锅、食品安全等
- **进阶技巧**：油温判断、糖色炒制、辅料技巧、高级专业术语
- **分类展示**：按"技巧"和"常识"分类
- **Markdown 渲染**：支持丰富的文本格式

## 🛠 技术栈

| 技术 | 说明 |
|------|------|
| **语言** | Kotlin |
| **UI 框架** | Jetpack Compose（声明式 UI） |
| **架构模式** | MVVM |
| **本地数据库** | Room（收藏数据持久化） |
| **图片加载** | Coil（异步图片加载） |
| **导航** | Navigation Compose（页面路由） |
| **JSON 解析** | Gson（数据解析） |
| **Markdown** | compose-markdown（技巧文章渲染） |

## 🚀 构建运行

### 环境要求

- Android Studio Hedgehog 或更高版本
- JDK 17+
- Android SDK 34
- Gradle 8.7+

### 步骤

1. 克隆仓库
   ```bash
   git clone https://github.com/ajie203b/XuJiaCaiPu.git
   cd XuJiaCaiPu/android_project
   ```

2. 用 Android Studio 打开项目

3. 同步 Gradle 并运行（支持模拟器或真机）
